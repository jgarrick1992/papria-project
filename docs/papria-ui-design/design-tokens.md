# Papria 设计 Tokens

## 1. 共同原则

- 界面文案为中文，产品与服务名保持 `Papria`、`BookOrbit`。
- 正常版以长期阅读舒适度为优先；水墨屏版以可读性、稳定布局和低刷新适配为优先。
- 图标使用平台系统图标体系：Android Material Symbols Rounded，iOS SF Symbols。图标不以文字圆角按钮替代。
- 正文、进度、失败和离线状态均不能只依赖颜色，需要同时有图标或明确文本。
- 所有布局以 8 为基线。长书名、作者和服务器地址必须截断或换行，不能推动固定高度控制条变形。

## 2. 正常版颜色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `paper.canvas` | `#F7F2E8` | 页面主背景，暖白纸张 |
| `paper.raised` | `#FFFCF6` | 工具栏、底部栏、轻量面板 |
| `ink.primary` | `#20221F` | 标题、正文、主要图标 |
| `ink.secondary` | `#6F6C63` | 元数据、次级说明 |
| `ink.disabled` | `#9B978D` | 禁用文案与图标 |
| `line.subtle` | `#D8D0C3` | 分隔线、输入框边界 |
| `action.primary` | `#B74632` | 主操作、当前阅读进度、错误重点 |
| `action.pressed` | `#8F3425` | 主操作按下态 |
| `status.success` | `#2D7168` | 已同步、传书完成、下载完成 |
| `status.remote` | `#3D668B` | BookOrbit、远程资源、网络连接 |
| `status.warning` | `#9C661A` | 暂停、仅 Wi-Fi、需注意状态 |
| `status.error` | `#B74632` | 下载失败、连接失败、不可恢复错误 |
| `focus.ring` | `#3D668B` | 键盘焦点和无障碍焦点 |

正常版不可使用紫色或蓝紫渐变替代主题色。背景可有细微纸张颗粒感，但不得影响 14sp 及以上正文的对比度。

## 3. 水墨屏颜色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `eink.black` | `#000000` | 主正文、已选中项填充、重点操作 |
| `eink.charcoal` | `#292929` | 次级正文和图标 |
| `eink.mid` | `#757575` | 次级状态、禁用文字 |
| `eink.pale` | `#D5D5D5` | 分隔线、未完成进度轨道 |
| `eink.white` | `#FFFFFF` | 画布、反白选中项文字 |

水墨屏不使用颜色语义、阴影、半透明浮层、模糊和渐变。成功、失败、暂停、离线必须以词语、图标和线型区分，例如 `已完成`、`失败`、`暂停`、`离线`。

## 4. 字体与字号

| 场景 | 正常版 Android | 正常版 iOS | 水墨屏 Android |
| --- | --- | --- | --- |
| UI 字体 | Noto Sans CJK SC / 系统 sans | PingFang SC | Noto Sans CJK SC / 系统 sans |
| 阅读正文 | 系统衬线体或用户选择字体 | Songti SC / 用户选择字体 | 高可读系统衬线体 |
| 页面标题 | 24sp, 32 行高, 600 | 22pt, 30 行高, semibold | 22px, 30 行高, 700 |
| 区域标题 | 17sp, 24 行高, 600 | 17pt, 24 行高, semibold | 18px, 25 行高, 700 |
| 列表正文 | 16sp, 24 行高, 400 | 16pt, 23 行高, regular | 17px, 25 行高, 500 |
| 元数据 | 13sp, 18 行高, 400 | 13pt, 18 行高, regular | 14px, 20 行高, 400 |
| 辅助标签 | 12sp, 16 行高, 500 | 12pt, 16 行高, medium | 13px, 18 行高, 600 |
| 阅读正文默认 | 19sp, 1.75 倍行距 | 19pt, 1.72 倍行距 | 21px, 1.65 倍行距 |

字距为 `0`。不使用随视口宽度缩放的字体。阅读器必须允许用户调整字号、行距、边距和页面颜色；水墨屏默认分页而非滚动。

## 5. 间距、尺寸与圆角

| Token | 正常版 | 水墨屏版 | 说明 |
| --- | ---: | ---: | --- |
| `space.1` | 4 | 4 | 图标与短标签 |
| `space.2` | 8 | 8 | 默认内间距基线 |
| `space.3` | 12 | 12 | 列表内容间距 |
| `space.4` | 16 | 16 | 页面水平内边距 |
| `space.5` | 24 | 20 | 区域间距 |
| `space.6` | 32 | 24 | 大区块间距 |
| `touch.min` | Android 48dp，iOS 44pt | 48px | 所有可点目标最小尺寸 |
| `toolbar.height` | Android 64dp，iOS 56pt + 安全区 | 48px | 顶部工具栏 |
| `tabbar.height` | Android 72dp，iOS 49pt + 安全区 | 52px | 一级导航 |
| `radius.control` | 6 | 0 或 2px | 输入、按钮、选择器 |
| `radius.panel` | 8 | 0 | 正常版轻量面板；水墨屏无卡片感 |
| `rule.width` | 1dp | 1px | 明确但不喧宾夺主 |

正常版允许低强度阴影：`0 2 8 rgba(32,34,31,0.08)`，仅用于底部播放器、悬浮任务面板和模态层。水墨屏阴影恒为 `none`。

## 6. 组件状态

| 组件 | 默认 | 加载 | 成功 | 失败 / 离线 |
| --- | --- | --- | --- |
| 书籍行 | 标题、作者、格式、进度 | 封面骨架和静态占位线 | `已下载` 或 `已同步` 标签 | `文件不可用`，附重试入口 |
| 主按钮 | 砖红底白字 | 固定宽度内显示进度或转圈 | 成功后变为次操作 | 显示错误说明，不自动消失 |
| 下载任务 | 文件、大小、细进度条 | 进度、速率、暂停图标 | `已完成` 和打开入口 | `失败`、原因、`重试` |
| 连接状态 | BookOrbit 域名和状态 | `正在连接` | `已连接` | `离线` / `无法连接` |
| 同步冲突 | 冲突数量 | 比对中 | 已处理计数 | 本地和服务器版本并列选择 |

水墨屏加载不使用连续旋转动画，改为静态 `正在载入` 文案、三段式固定进度或显式刷新按钮。水墨屏选择态使用黑底白字或 2px 黑色外框，不使用灰色低对比 hover。

## 7. 图标规则

| 行为 | Android | iOS | 可见文字 |
| --- | --- | --- |
| 书库 | `library_books` | `books.vertical` | `书库` |
| BookOrbit | `cloud_queue` | `cloud` | `BookOrbit` |
| 传书 | `wifi_tethering` | `wifi` | `传书` |
| 设置 | `settings` | `gearshape` | `设置` |
| 下载任务 | `download` | `arrow.down.circle` | `任务` |
| 搜索 | `search` | `magnifyingglass` | 有可访问性标签 |
| 筛选 | `tune` | `line.3.horizontal.decrease.circle` | `筛选` |
| 重试 | `refresh` | `arrow.clockwise` | `重试` |
| 暂停 / 播放 | `pause` / `play_arrow` | `pause.fill` / `play.fill` | 需要文字或辅助标签 |

图标按钮必须有无障碍标签和按下反馈。正常版按下态可降低透明度，水墨屏按下态只允许反白或边框加粗。
