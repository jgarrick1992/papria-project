# Papria 高保真 PNG 生成提示词

## 使用规则

- 每条提示词生成一张独立 PNG，文件名和画布尺寸必须与下表一致。
- 画面是平视的 2D 原生应用截图，不要手机硬件外框、手、桌面、环境摄影、瀑布流网页或营销落地页。
- 必须使用清晰、简体中文界面文字。若模型无法保证长段落文字，优先保持页面结构和短标签正确；以本目录 Markdown 规范中的中文文案为实现真值。
- 书封只用原创抽象图形、纸纹、线条和几何构图，不出现真实出版物、作者头像、商标、水印或受版权保护封面。
- 所有画面不得带渐变背景、紫色主题、圆角大卡片堆叠、无意义装饰光球或英文占位文本。
- 正常版使用暖白纸张、深墨、砖红、青绿和远程资源蓝；水墨屏只允许黑、白与灰阶。

## 生成后验收

1. 每张图检查是否为指定画布尺寸、单一应用界面或指定总览板，并且文件名完全对应。
2. 检查正常版是否使用暖白、深墨、砖红、青绿、蓝色，而非单一蓝紫或深色主题。
3. 检查水墨屏是否只使用黑白灰，无阴影、渐变、色彩状态和自动隐藏控制栏。
4. 检查 iOS 图中没有 Android 导航控件，水墨屏图中没有 iOS 语境。
5. 检查关键短文案、下载进度、离线、失败重试、仅 Wi-Fi、冲突选择和四个一级入口均可见；若文字失真，使用同一提示词局部重生成，直至短标签清晰。
