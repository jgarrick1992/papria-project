# Papria 交互规范

## 1. 信息架构与导航

正常版和水墨屏版都使用四个核心入口：`书库`、`BookOrbit`、`传书`、`设置`。Android 使用带图标和文字的底部导航；iOS 使用系统 Tab Bar 与安全区。水墨屏底部导航保持静态，不做滑动指示或动效。

| 入口 | 默认内容 | 关键二级入口 | 返回规则 |
| --- | --- | --- | --- |
| 书库 | 继续阅读、最近导入、全部书籍 | 搜索、筛选、书籍详情、阅读器 | 阅读器返回到原书籍上下文 |
| BookOrbit | 登录或远程书库 | 搜索、书籍详情、任务中心 | 详情返回目录，任务返回来源页 |
| 传书 | Wi-Fi 地址、二维码、传输列表 | 上传详情、完成结果 | 保持服务器运行状态直到用户停止 |
| 设置 | 服务器、显示、同步、存储 | 服务器编辑、阅读设置、冲突处理 | 保存即刻生效；危险操作二次确认 |

任务中心不是一级 Tab。它由 BookOrbit 顶部的下载图标或下载中的书籍条目进入，返回时保留此前的筛选和滚动位置。

## 2. 书库与阅读

### 书库状态

| 状态 | 视觉内容 | 主操作 |
| --- | --- | --- |
| 空书库 | 线性书架图标、`还没有书籍`、两句短说明 | `传书`、`从文件导入` |
| 已导入 | 继续阅读横条、最近导入列表、格式和进度 | 点书继续阅读 |
| 搜索中 | 顶部固定搜索框、结果数、筛选芯片 | 清除、筛选 |
| 无结果 | 保留搜索词、`未找到匹配书籍` | 清除筛选 |
| 文件失效 | 书籍行内显示 `文件不可用` | 重新定位或移除记录 |

书籍详情显示封面、标题、作者、格式、最后阅读位置、同步状态和主要操作。长标题最多两行，作者和格式不抢占主操作。EPUB、PDF、漫画和文本均从相同详情结构进入对应阅读器。

### 阅读器

- EPUB / 文本默认使用暖白阅读画布、深墨正文、底部细进度和当前章节。轻点中央区域呼出控制栏。
- PDF 默认保留页面比例和页码；双击缩放、手势平移的同时必须有明确的重置缩放入口。
- 漫画默认单页适配宽度；切换可选的连续滚动时，阅读位置按页保存。
- 水墨屏阅读器默认分页。上一页、下一页有大触控区，顶栏只显示返回、章节和页码，底栏静态显示页码和电量区域，不自动淡出。
- 阅读进度在本地立即写入；远程可用时排队同步。同步失败不阻断阅读，只在书籍详情或设置中给出可处理的状态。

## 3. BookOrbit、下载与离线

### 登录与连接

初次进入 BookOrbit 时显示服务器地址、账号、密码或令牌输入。`连接并登录` 是唯一主操作。连接中按钮保持固定尺寸并显示 `正在连接`；失败在输入区域下方给出原因与 `重试`，不清空用户输入。

已登录时，顶部显示当前服务器名称和连接状态。离线状态保持已缓存的书目可浏览，并在页面顶部显示非阻塞的 `离线：仅显示已缓存内容` 提示。需要网络的下载按钮变为 `等待网络`，用户可选择取消或保留队列。

### 下载任务

| 状态 | 行内信息 | 可执行操作 |
| --- | --- | --- |
| 等待 | 队列顺序、`等待网络` 或 `等待 Wi-Fi` | 取消、立即下载（满足条件时） |
| 下载中 | 已下载 / 总大小、进度、速率 | 暂停、取消 |
| 暂停 | `已暂停`、已下载大小 | 继续、取消 |
| 失败 | `失败`、可理解的原因 | 重试、删除 |
| 已完成 | `已完成`、文件格式 | 打开、从设备移除 |

`仅 Wi-Fi 下载` 是一个开关。在蜂窝网络或无 Wi-Fi 时，任务必须明确显示为等待状态，不能伪装为正在下载。失败任务不自动无限重试；默认只在用户点击 `重试` 或网络状态明显恢复后提示重试。

水墨屏任务行使用文本进度如 `42%  18/43 MB` 和黑色实线进度条，不使用彩色、细微动画或只含图标的状态。

## 4. 音频阅读

音频阅读可从书籍详情或阅读器的音频资源入口打开。播放器显示书名、章节、当前时间 / 总时长、拖动进度、上一段、播放 / 暂停、下一段、倍速、睡眠计时。

- 播放 / 暂停必须是最显眼、最小 48dp / 44pt 的控制。
- 跳转按钮的默认步长为 15 秒，可在设置中调整。
- 倍速使用菜单，默认 `1.0x`，支持 `0.8x`、`1.0x`、`1.25x`、`1.5x`、`2.0x`。
- 睡眠计时使用 `关闭`、`15 分钟`、`30 分钟`、`本章结束`。计时结束后暂停并保留位置。
- 后台播放时系统通知或锁屏控件与当前播放状态一致。无音频焦点时暂停，并在回到应用后显示原因。

水墨屏不在阅读正文上叠加动态迷你播放器。音频模式进入单独的静态播放页，封面缩小为灰阶缩略图。

## 5. Wi-Fi 传书

传书页启动局域网服务后，依次显示网络名称、局域网地址、二维码、`保持此页面打开` 说明和最近传输列表。二维码旁必须有可复制的纯文本地址，不要求用户只扫描二维码。

| 状态 | 页面表现 | 交互 |
| --- | --- | --- |
| 未启动 | 简短安全说明 | `启动传书` |
| 运行中 | 地址、二维码、停止按钮、等待上传 | `复制地址`、`停止` |
| 上传中 | 文件名、大小、稳定进度条 | 取消单文件 |
| 校验 / 导入 | `正在导入` 与静态进度 | 不允许重复打开同一文件 |
| 完成 | `已加入书库`、书籍数量 | `查看书库` |
| 失败 | 文件名和失败原因 | `重试` 或移除 |

水墨屏二维码使用白底黑码、周围至少 16px 留白；地址用大号等宽数字和字母显示。结束服务必须有确认，避免误触后中断上传。

## 6. 设置、同步冲突与危险操作

设置按以下顺序分组：BookOrbit 服务器、阅读显示、下载与存储、同步、关于。连接状态、当前显示模式和存储余量可在各组标题旁短显，但不要用多个卡片包装。

同步冲突页并列显示本地与服务器版本的阅读位置、更新时间和设备名称。用户可选择 `保留本地进度`、`使用服务器进度`、`稍后处理`。选择后必须给出可撤销提示或在下一次同步前保留恢复点。

| 操作 | 确认要求 |
| --- | --- |
| 停止 Wi-Fi 传书 | 有上传时确认 |
| 删除本地书籍 | 确认，并说明远程副本是否保留 |
| 清空下载队列 | 有未完成项目时确认 |
| 退出 BookOrbit | 确认是否保留离线缓存 |
| 覆盖同步进度 | 二次确认，显示将保留哪一方 |

## 7. 平台和动效约束

正常版允许 150 至 200ms 的淡入、展开和底部面板过渡，但页面切换不应延迟阅读操作。加载骨架必须和最终内容保持相同高度，防止列表跳动。

水墨屏不使用渐变、阴影、骨架闪烁、连续旋转、浮动按钮位移动画或自动隐藏控制栏。状态变化以完整区域刷新、反白选择态或 1px 进度条长度变化表达。
