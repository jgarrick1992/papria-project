# Papria UI Change 0.1.0

> 文档类型：UI 变更规格 · 版本：`0.1.0` · 状态：已实施（代码与自动化门禁完成） · 设计状态：逐屏真机、服务端和无障碍证据仍待补充
> 设计基线：[`docs/papria-ui-design`](../papria-ui-design/README.md)

## 1. 目的与范围

本文档定义 Papria `0.1.0` 的移动端 UI 目标，用于后续 Android Compose 与
iOS SwiftUI 实施、评审和验收。本文档描述的是目标状态，不代表对应页面、交互或
真机体验已经在当前代码中完成。

本次设计覆盖三个交付面：

| 设计版本 | 平台 | 参考逻辑尺寸 | 目标 |
| --- | --- | --- | --- |
| 正常版 Android | Android | 360 x 800dp | 纸张书房感、Material 导航习惯、高频操作效率 |
| 正常版 iOS | iOS | 390 x 844pt | 共用 Papria 视觉语言，保留 iOS 导航、安全区和系统控件习惯 |
| 水墨屏版 | Android | 600 x 800px | 黑白高对比、单列紧凑、低刷新、分页阅读优先 |

iOS 只实施正常版，不实施水墨屏版本。本文中的示例书名、作者、服务器域名、文件
大小、阅读位置和进度仅用于说明信息层级，不能作为生产数据写入实现。

## 2. 设计依据与冲突处理

实施和评审必须按以下优先级读取设计依据：

1. [`design-tokens.md`](../papria-ui-design/design-tokens.md)：颜色、字号、行高、间距、尺寸、圆角、阴影和图标的精确值。
2. [`interaction-spec.md`](../papria-ui-design/interaction-spec.md)：导航、状态、操作、确认、失败和返回行为。
3. [`screen-inventory.md`](../papria-ui-design/screen-inventory.md)：页面范围、平台范围、跨页面组件和状态覆盖。
4. 对应 PNG：页面构图、信息层级、组件顺序、视觉密度和空间关系。
5. [`imagegen-prompts.md`](../papria-ui-design/imagegen-prompts.md)：只补充 PNG 中难以辨认的示例文案，不覆盖正式规范。

发生冲突时遵守以下规则：

- 精确数值和交互行为以 Markdown 规范为准。
- 页面构图、信息层级和组件顺序以对应单屏 PNG 为准。
- 当前 Android / iOS 页面只用于识别变更，不得覆盖设计稿目标。
- 不复制 PNG 中的生成瑕疵、错字、变形图标或不可实现控件。
- 不新增设计目录没有定义的一级入口、字段、状态或兼容映射。
- Android 使用 Material Symbols Rounded，iOS 使用 SF Symbols；不得跨平台照搬控件外形。
- 页面使用真实业务数据，示例封面只可作为原创占位资源，不得替换为受版权限制的真实封面。

## 3. 当前界面与目标差异

| 平台 / 区域 | 当前状态 | `0.1.0` 目标 |
| --- | --- | --- |
| Android 一级导航 | 顶部 `书库 / BookOrbit / 下载 / Wi-Fi` Tab | 底部 `书库 / BookOrbit / 传书 / 设置` 四入口导航 |
| Android 下载 | 一级 Tab | BookOrbit 顶部任务入口进入的二级任务中心 |
| Android 显示模式 | 书库顶部直接选择普通 / 水墨 | 设置中的“阅读显示”分组 |
| Android 设置 | 没有独立一级入口 | 新增固定的 `设置` 一级入口 |
| iOS 一级导航 | `书库 / 传书 / 设置` 三 Tab | `书库 / BookOrbit / 传书 / 设置` 四个系统 Tab |
| iOS 书库 | 本地书籍与 BookOrbit 远程书籍混排 | 书库只管理本地内容；BookOrbit 独立成一级入口 |
| 正常版视觉 | 平台默认配色为主 | 统一的纸张、深墨、砖红、青绿和远程蓝视觉语言 |
| 水墨屏视觉 | 已有模式开关和部分分页限制 | 完整黑白 token、单列结构、静态状态和低刷新交互 |
| 任务与冲突 | 信息和操作较紧凑，入口分散 | 独立任务中心、设置内冲突处理和完整状态语义 |

本次只重构信息架构、视觉呈现和操作入口。阅读、下载、同步、BookOrbit 和 Wi-Fi
传书的业务语义保持不变。

## 4. 全局信息架构

正常版和水墨屏版共用以下四个一级入口，名称、顺序和职责不可调整：

| 顺序 | 入口 | 默认内容 | 二级入口 | 返回要求 |
| ---: | --- | --- | --- | --- |
| 1 | `书库` | 继续阅读、最近导入、全部书籍 | 搜索、筛选、书籍详情、阅读器 | 阅读器返回原书籍上下文 |
| 2 | `BookOrbit` | 登录或远程书库 | 搜索、书籍详情、下载任务中心 | 返回时保留筛选和滚动位置 |
| 3 | `传书` | Wi-Fi 地址、二维码、传输列表 | 上传详情、完成结果 | 服务状态按现有安全边界保持或停止 |
| 4 | `设置` | 服务器、显示、下载、同步、关于 | 服务器编辑、阅读设置、冲突处理 | 设置保存后立即反映；危险操作确认 |

Android 正常版使用带图标和文字的 Material 底部导航；iOS 使用系统 Tab Bar 和安全区；
水墨屏底部导航保持静态，不使用滑动指示、位移动画或自动隐藏。下载任务中心不是一级
入口，必须从 BookOrbit 顶部任务图标或下载中的文件行进入。

### 5.1 正常版颜色

| --- | --- | --- |
| `paper.canvas` | `#F7F2E8` | 页面主背景和阅读画布 |
| `paper.raised` | `#FFFCF6` | 工具栏、底部栏、轻量面板 |
| `ink.primary` | `#20221F` | 标题、正文、主要图标 |
| `ink.secondary` | `#6F6C63` | 作者、格式、大小、时间和次级说明 |
| `ink.disabled` | `#9B978D` | 禁用文案与图标 |
| `line.subtle` | `#D8D0C3` | 分隔线和输入框边界 |
| `action.primary` | `#B74632` | 主操作、当前导航、阅读和下载进度 |
| `action.pressed` | `#8F3425` | 主操作按下态 |
| `status.success` | `#2D7168` | 已同步、已缓存、传书和下载完成 |
| `status.remote` | `#3D668B` | BookOrbit、远程资源和网络连接 |
| `status.warning` | `#9C661A` | 暂停、仅 Wi-Fi 和待处理状态 |
| `status.error` | `#B74632` | 下载失败、连接失败和不可恢复错误 |
| `focus.ring` | `#3D668B` | 键盘与无障碍焦点 |

正常版禁止使用紫色或蓝紫渐变替代主题色。纸张颗粒只能作为极轻微背景质感，不能影响
正文对比度，也不能形成装饰性渐变或光斑。

### 5.2 水墨屏颜色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `eink.black` | `#000000` | 正文、选中项填充、重点操作和完成进度 |
| `eink.charcoal` | `#292929` | 次级正文和图标 |
| `eink.mid` | `#757575` | 次级状态和禁用文字 |
| `eink.pale` | `#D5D5D5` | 分隔线和未完成进度轨道 |
| `eink.white` | `#FFFFFF` | 画布和反白文字 |

水墨屏禁止颜色语义、阴影、半透明浮层、模糊、渐变和纸张纹理。成功、失败、暂停、
等待和离线必须同时显示明确文字，不能只依赖灰度差异。

### 5.3 字体与字号

| 场景 | 正常版 Android | 正常版 iOS | 水墨屏 Android |
| --- | --- | --- | --- |
| UI 字体 | Noto Sans CJK SC / 系统 sans | PingFang SC | Noto Sans CJK SC / 系统 sans |
| 阅读正文 | 系统衬线体或用户选择字体 | Songti SC / 用户选择字体 | 高可读系统衬线体 |
| 页面标题 | 24sp / 32 / 600 | 22pt / 30 / semibold | 22px / 30 / 700 |
| 区域标题 | 17sp / 24 / 600 | 17pt / 24 / semibold | 18px / 25 / 700 |
| 列表正文 | 16sp / 24 / 400 | 16pt / 23 / regular | 17px / 25 / 500 |
| 元数据 | 13sp / 18 / 400 | 13pt / 18 / regular | 14px / 20 / 400 |
| 辅助标签 | 12sp / 16 / 500 | 12pt / 16 / medium | 13px / 18 / 600 |
| 阅读正文默认 | 19sp / 1.75 倍行距 | 19pt / 1.72 倍行距 | 21px / 1.65 倍行距 |

字距固定为 `0`。禁止使用随视口宽度缩放的字体。阅读器必须允许用户调整字号、行距、
边距和页面颜色；水墨屏默认分页而不是滚动。

### 5.4 间距、尺寸和层级

| Token / 元素 | 正常版 | 水墨屏版 | 规则 |
| --- | ---: | ---: | --- |
| `space.1` | 4 | 4 | 图标与短标签 |
| `space.2` | 8 | 8 | 默认内间距基线 |
| `space.3` | 12 | 12 | 列表内容间距 |
| `space.4` | 16 | 16 | 页面水平内边距 |
| `space.5` | 24 | 20 | 区域间距 |
| `space.6` | 32 | 24 | 大区块间距 |
| 最小触控区 | Android 48dp；iOS 44pt | 48px | 所有可操作元素 |
| 顶部栏 | Android 64dp；iOS 56pt + 安全区 | 48px | 高度稳定，不被动态内容撑开 |
| 底部导航 | Android 72dp；iOS 49pt + 安全区 | 52px | 高度稳定，不遮挡列表 |
| 控件圆角 | 6 | 0 或最多 2px | 输入、按钮、选择器 |
| 面板圆角 | 最大 8 | 0 | 禁止卡片嵌套 |
| 分隔线 | 1dp | 1px | 清晰但不喧宾夺主 |

正常版只允许 `0 2 8 rgba(32,34,31,0.08)` 的低强度阴影，并且只用于底部播放器、
悬浮任务面板和模态层。普通页面区域不得做成漂浮卡片，卡片内不得再嵌套卡片。

### 5.5 图标

| 行为 | Android | iOS | 可见或辅助文案 |
| --- | --- | --- | --- |
| 书库 | `library_books` | `books.vertical` | `书库` |
| BookOrbit | `cloud_queue` | `cloud` | `BookOrbit` |
| 传书 | `wifi_tethering` | `wifi` | `传书` |
| 设置 | `settings` | `gearshape` | `设置` |
| 下载任务 | `download` | `arrow.down.circle` | `任务` |
| 搜索 | `search` | `magnifyingglass` | 无障碍标签 `搜索` |
| 筛选 | `tune` | `line.3.horizontal.decrease.circle` | `筛选` |
| 重试 | `refresh` | `arrow.clockwise` | `重试` |
| 暂停 / 播放 | `pause` / `play_arrow` | `pause.fill` / `play.fill` | 必须有文字或辅助标签 |

图标按钮必须有无障碍标签和按下反馈。正常版按下态可降低透明度；水墨屏按下态只允许
反白或边框加粗。

### 5.6 动效

- 正常版只使用 150–200ms 的淡入、展开和底部面板过渡。
- 页面切换、打开阅读器和翻页不能等待装饰性动画。
- 加载骨架必须与最终内容等高，防止列表跳动。
- 水墨屏不使用骨架闪烁、连续旋转、渐变过渡、浮动按钮位移动画或自动隐藏控制栏。
- 水墨屏状态变化只通过完整区域刷新、反白选择态、边框加粗或进度线长度变化表达。

## 6. 正常版逐屏规格

### 6.1 N01 Android 书库

设计依据：[`normal-library-android-360.png`](../papria-ui-design/normal-library-android-360.png)

页面从上到下固定为顶部栏、继续阅读、书籍列表和底部导航，不在这些区域外增加英雄区、
说明卡片或常驻模式选择器。

#### 顶部栏

- 标题固定为 `书库`。
- 右侧依次放置搜索和筛选 Material 系统图标。
- 搜索打开固定高度搜索框，保留当前查询、结果数和筛选状态。
- 筛选使用筛选控件或菜单，不把选项平铺成会挤压标题的按钮行。

#### 继续阅读

- 区域标题为 `继续阅读`。
- 显示最近阅读书籍的封面、书名、作者、阅读百分比和当前页 / 总页数。
- 主操作固定为 `继续阅读`，点击后恢复保存位置。
- 已完成进度使用 `action.primary`，同时显示 `68%` 等文字，不能只显示色条。
- 没有阅读历史时不显示空卡片，直接让书籍列表接续顶部栏。

#### 最近导入与全部书籍

- 书籍行包含封面、最多两行书名、作者、格式、阅读进度和本地 / 远程状态。
- 本地文件、BookOrbit 已下载文件和待同步状态必须有文字或图标加文字标识。
- 元数据使用 `ink.secondary`，不能与主标题竞争。
- 删除本地副本通过长按、菜单或其他平台上下文操作进入，不在每行常驻大型删除按钮。
- 删除确认必须说明只删除本地副本，远程副本是否保留。

#### 底部导航

- 顺序固定为 `书库`、`BookOrbit`、`传书`、`设置`。
- 图标和文字同时可见。
- 当前 `书库` 使用 `action.primary`，其他入口使用次级墨色。
- 导航高度为 72dp，列表底部必须包含相应安全内边距。

#### 状态

| 状态 | 页面表现 | 操作 |
| --- | --- | --- |
| 空书库 | 线性书架图标、`还没有书籍`、两句短说明 | `传书`、`从文件导入` |
| 搜索中 | 固定搜索框、结果数、筛选状态 | 清除查询、调整筛选 |
| 无结果 | 保留搜索词，显示 `未找到匹配书籍` | 清除筛选 |
| 文件失效 | 书籍行内显示 `文件不可用` 和原因 | 重新定位或移除记录 |
| 离线 | 本地书库正常可用 | 远程同步延迟处理 |

### 6.2 N02 iOS 书库

设计依据：[`normal-library-ios-390.png`](../papria-ui-design/normal-library-ios-390.png)

- 使用系统 Navigation Bar、Navigation Stack / 等价原生导航、安全区和系统 Tab Bar。
- 内容顺序和信息层级与 N01 一致：顶部标题、继续阅读、最近导入 / 全部书籍、Tab Bar。
- 搜索图标使用 SF Symbol `magnifyingglass`，并提供 `搜索` 无障碍标签。
- Tab 顺序固定为 `书库`、`BookOrbit`、`传书`、`设置`。
- 删除本地副本使用 iOS swipe action；执行前显示明确确认。
- 不使用 Android TopAppBar、Material 控件或自绘仿 Android 底部导航。
- 在 390 x 844pt 基准下，Navigation Bar、动态岛 / 状态区和 Tab Bar 不能遮挡内容。
- Dynamic Type 放大时允许书名和元数据换行，固定工具栏和 Tab Bar 高度不能被内容撑开。

N01 的空、搜索、无结果、文件失效和离线状态同样适用于 iOS，呈现必须使用原生 iOS
控件和反馈方式。

### 6.3 N03 BookOrbit 书籍详情

设计依据：[`normal-bookorbit-detail.png`](../papria-ui-design/normal-bookorbit-detail.png)

该页面的内容顺序由 Android / iOS 共用；Android 使用 Material 导航，iOS 使用系统
Navigation Bar 和 SF Symbols。

#### 顶部与连接状态

- 顶部顺序为返回、标题 `BookOrbit`、下载任务入口。
- 下载任务入口存在未完成任务时显示数字角标；没有任务时不显示空角标。
- 顶部状态行显示服务器域名和 `正在连接`、`已连接`、`离线` 或 `无法连接`。
- 远程连接使用 `status.remote`，但必须同时显示文字状态。

#### 书籍信息

- 显示封面、书名、作者和远程资源状态。
- 书名最多两行；作者、格式和服务器信息不能挤压文件操作。
- 封面加载失败使用稳定尺寸占位，不能导致文件列表上移或跳动。

#### 文件列表

每个实际文件独立成行，至少显示文件名 / 格式、文件大小、下载状态、Wi-Fi 限制和当前
可执行操作。EPUB、PDF、音频等格式不映射为其他兼容名称。

| 状态 | 必须显示 | 操作 |
| --- | --- | --- |
| 未下载 | 格式、大小 | 下载；可加入仅 Wi-Fi 队列 |
| 等待网络 | `等待网络`、队列状态 | 取消或保留队列 |
| 等待 Wi-Fi | `等待 Wi-Fi`、大小 | 取消；满足条件后继续 |
| 下载中 | 百分比、已下载 / 总大小、稳定进度条 | 暂停、取消 |
| 已暂停 | `已暂停`、已下载大小 | 继续、取消 |
| 失败 | `失败` 和可理解原因 | 重试、删除任务 |
| 已完成 | `已下载`、格式 | 打开、从设备移除 |

- 下载中不能只显示转圈。
- `等待 Wi-Fi` 不能伪装为下载中。
- 音频文件可显示在线播放入口，但不得挤压下载状态和主要操作。
- 页面底部显示任务摘要，例如 `1 项下载中，1 项等待 Wi-Fi`。
- 离线时保留已缓存书目和详情；需要网络的操作显示等待状态而不是立即失败后消失。

### 6.4 N04 EPUB / 文本阅读器

设计依据：[`normal-reader-epub.png`](../papria-ui-design/normal-reader-epub.png)

#### 页面结构

- 阅读画布使用 `paper.canvas`，正文使用 `ink.primary`。
- 顶部阅读栏顺序为返回、书名、目录、显示设置。
- 正文区域先显示章节标题，再显示连续正文；正文不能放入卡片容器。
- 底部控制栏显示当前章节、阅读进度条、百分比、当前页 / 总页数、上一页、下一页和字体设置。
- 控制栏不得覆盖正文；显示和隐藏不能改变正文排版宽度或造成页面跳动。

#### 排版与交互

- Android 默认正文 19sp、1.75 倍行距。
- iOS 默认正文 19pt、1.72 倍行距。
- 用户可以调整字号、行距、边距、字体和页面颜色。
- 正常版轻点正文中央区域呼出或隐藏控制栏，使用 150–200ms 过渡。
- 目录和显示设置从对应系统图标进入，不使用大号文字圆角按钮替代图标。
- 阅读位置在本地立即保存；远程同步失败不阻断阅读。

#### 其他阅读格式

- PDF 沿用相同顶栏、画布和底栏视觉体系，保留页面比例、页码、双击缩放、手势平移和重置缩放入口。
- 漫画沿用相同视觉体系，默认单页适配宽度；连续滚动作为可选模式，位置按页保存。
- 解析失败显示文件名、失败原因和可执行返回 / 重试入口，不能只显示空白阅读面。

## 8. 状态覆盖矩阵

每个核心流程都必须实现可复现的空、加载、成功、失败和离线状态。PNG 不要求为每个
状态单独提供一张页面，但所有状态必须遵守相同视觉和交互规则。

| 核心流程 | 空 | 加载 | 成功 | 失败 | 离线 |
| --- | --- | --- | --- | --- | --- |
| 本地书库 | 空书库引导 | 导入扫描占位 | 已加入书库 | 文件不可用 | 本地内容正常可用 |
| BookOrbit | 未登录 | 正在连接 / 载入目录 | 已连接、书目可用 | 登录或目录请求失败 | 缓存目录、网络操作等待 |
| 文件下载 | 无任务 | 下载中 | 已完成 / 可打开 | 失败 / 重试 | 等待网络或等待 Wi-Fi |
| 阅读器 | 无可读文件 | 打开书籍 | 已保存阅读位置 | 解析失败 | 继续本地阅读、延迟同步 |
| 音频 | 无音频资源 | 加载章节 | 播放 / 已缓存 | 焦点或解码失败 | 已缓存章节可播放 |
| Wi-Fi 传书 | 服务未启动 | 上传 / 导入 | 已加入书库 | 上传或导入失败 | 局域网地址不可用 |
| 设置 / 同步 | 无冲突 | 比对进度 | 冲突已处理 | 保存设置失败 | 显示最后同步时间 |

状态消息不能自动消失到用户无法处理。加载、失败、暂停、完成和离线都必须保持组件
尺寸稳定，不能使列表、工具栏、阅读正文或底部导航发生突跳。

## 9. 确认与失败处理

| 操作 | 确认要求 |
| --- | --- |
| 停止 Wi-Fi 传书 | 有活动上传时确认，并说明上传将中断 |
| 删除本地书籍 | 确认只删除本地副本，并说明远程副本是否保留 |
| 清空下载队列 | 有未完成任务时确认 |
| 退出 BookOrbit | 确认是否保留离线缓存 |
| 覆盖同步进度 | 二次确认，并显示将保留和覆盖哪一方 |

连接失败不能清空用户已经输入的服务器和账号。下载失败不能无限自动重试。同步失败
不能阻断本地阅读。Wi-Fi 上传或导入失败必须保留文件名和失败原因。

## 10. 无障碍与内容稳定性

- 状态不能只依赖颜色或灰度，必须同时有图标、线型或明确文字。
- 图标按钮必须提供平台无障碍标签和按下反馈。
- 所有触控区满足 Android 48dp、iOS 44pt、水墨屏 48px。
- 长书名最多两行；超长作者、文件名和服务器地址必须截断或换行。
- 动态文本不能改变固定工具栏、播放器控制区和底部导航高度。
- 正文、按钮、状态和元数据不能相互遮挡。
- 二维码必须同时提供可复制、可选择和可朗读的文本地址。
- 播放、暂停、重试、等待、离线和失败必须有可访问的状态说明。
- iOS 必须适配安全区和 Dynamic Type；Android 必须适配系统字体缩放和系统栏。
- 水墨屏焦点和选中态使用反白或粗边框，不能使用低对比 hover。

## 11. 接口影响与非目标

本 UI 变更不调整公共 API、JSON 字段、变量名、字典 key 或数据映射，也不增加别名、
备用 key、端点回退或隐式兼容逻辑。

以下内容不在本次变更范围：

- BookOrbit v2.5.0 路由、认证和合同字段。
- 数据库 schema、迁移和本地数据保留策略。
- 阅读进度、音频进度和同步冲突的数据格式。
- Wi-Fi 传书协议、令牌、分块上传和安全边界。
- EPUB、PDF、漫画、文本、音频和其他文件格式的支持范围。
- DRM 拒绝策略。
- Android / iOS 以外的平台。
- iOS 水墨屏模式。
- 将设计稿中的示例书名、作者、域名、文件大小或进度写成固定业务数据。

### 12.1 截图矩阵

| 平台 | 基准视口 | 必须核对的页面 |
| --- | --- | --- |
| Android 正常版 | 360 x 800dp | N01、N03、N04、N05、N06、N07、N08 |
| iOS 正常版 | 390 x 844pt | N02，以及按 iOS 原生控件适配的 N03–N08 |
| Android 水墨屏 | 600 x 800px | E01、E02、E03、E04、E05、E06 |

### 12.2 必须通过的检查

- [ ] 四个一级入口的名称、顺序、图标和职责与设计稿一致。
- [ ] 下载任务中心不是一级 Tab。
- [ ] Android 正常版、iOS 正常版和 Android 水墨屏分别与对应 PNG 核对。
- [ ] 页面组件顺序、信息层级、状态文案和主次操作没有自行调整。
- [ ] 精确颜色、字号、行高、间距、尺寸、圆角和阴影与 tokens 一致。
- [ ] 页面没有异常文本截断、控件重叠、安全区遮挡或动态内容引起的布局位移。
- [ ] 正常版没有紫色、蓝紫渐变、装饰光斑、过量阴影、超规格圆角或卡片嵌套。
- [ ] 水墨屏没有颜色、渐变、阴影、连续动画、自动隐藏控制栏或仅靠图标表达的状态。
- [ ] 空、加载、成功、失败、离线、等待网络、等待 Wi-Fi、暂停和冲突状态均可复现。
- [ ] 所有图标按钮、播放器控制、二维码地址和状态提示可由辅助功能读取。
- [ ] 长标题、服务器地址、文件名和错误文案在基准视口及字体放大时保持可读。
- [ ] 删除、停止服务、清空队列、退出和覆盖进度按规范确认。
- [ ] BookOrbit、同步、下载、阅读和传书的业务合同没有因 UI 改造而改变。

### 12.3 证据要求

实施完成后，每个平台保存基准视口截图、空 / 失败 / 离线状态截图、字体放大截图和
关键交互录屏或测试记录。总览图只用于视觉方向评审，不能替代逐屏截图和状态验收。
