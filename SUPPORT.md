# Support policy

Papria is published as a source-only repository. The maintainer does not
provide general support, implementation assistance, feature-request intake, or
external pull-request review. No response, maintenance, or merge commitment is
made.

GitHub Issues are limited to reproducible bugs submitted with the Bug report
form. Do not include credentials, private books, personal data, or private
server URLs.

For a security vulnerability, do not open an issue. Report it only through
[GitHub Private Vulnerability Reporting](https://github.com/jgarrick1992/papria-project/security/advisories/new), as described in `SECURITY.md`.
