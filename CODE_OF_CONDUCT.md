# Code of Conduct

We are committed to making participation in this project a welcoming, respectful, and harassment-free experience for everyone.

Be constructive, assume good faith, respect different viewpoints, and keep technical discussions focused on the project and its users. Harassment, discrimination, personal attacks, doxxing, sexualized conduct, and publishing private information without consent are not acceptable.

For non-security conduct concerns, use GitHub's
[platform reporting channel](https://support.github.com/contact/report-abuse).
Do not use repository issues for conduct or security reports. Security
vulnerabilities must be reported only through the Private Vulnerability
Reporting route in `SECURITY.md`.
